# 本地学习计划App 需求清单

## 定位
安卓本地自用学习跟踪App，纯本地存储（SQLite），不上云、不联网、不社交。
技术栈：Java + Room + MPAndroidChart。

---

## 全局规则

1. **单次任务自动顺延**：昨天未完成的网课小节，第二天自动挪到今天。跨多天没打开App时，保留原计划日期显示为红色欠债，不自动批量改日期，由用户手动补或一键跳过。
2. **待办事项死线制**：过了ddl不自动改期，一直红色挂在首页待办区顶部，逾期天数累加，直到手动完成或删除。
3. **重复任务不欠债**：每天/每周几/每月几号自动出现，当天没打勾第二天自动消失，不顺延不逾期，到点重新出现一条新的。
4. **颜色规则**：
   - 当天新排任务 = 黑色文字
   - 顺延欠债任务 = 红色文字
   - 已完成 = 灰色划线
5. **计时**：开始后切到其他App继续走，结束自动写入学习记录。支持两种模式：
   - **正计时**：手动结束，最长3小时，到点静默自动停止保存。
   - **倒计时**：预设时长（如25分钟、45分钟），到点自动停止保存，不弹窗不提醒。
   - 每个科目可预设默认计时规则，开始计时选科目时自动带出，也可临时改。
   - **通知栏控制**：计时进行中，下拉通知栏有暂停/继续/结束按钮。
   - **同时只能有一个计时**：要给新任务开计时，必须先结束当前的。
6. **连续学习天数**：当天只要有任意学习时长记录就算一天，不要求完成任务。
7. **数据备份**：导出/导入JSON，导入为覆盖模式。导入目录时遇到同名科目自动追加，不新建。
8. **删除科目时**：下属章节、小节、计划全部删除，但历史学习记录保留，统计数据不受影响。

## Tab1 今日计划页（首页，默认进入）

### 顶部概览条
- 今日总任务数 / 已完成数
- 今日累计学习时长（计时中实时更新）

### 首页空状态
今天没有任何任务时：显示提示"今天没有安排任务，去科目目录排课吧"，同时显示最近逾期的待办。

### 待办事项区（固定在最上方）
死线型任务，有明确ddl。

每条待办包含：
- 标题（必填）
- ddl日期（必填）
- 完成状态（勾选框）
- 备注（可选）
- 绑定科目（可选）

添加方式：手动输入标题即可，不绑科目的待办在统计页归为"其他"。

显示规则：
- 未到期 = 正常颜色
- 今天就是ddl = 高亮
- 已过ddl = 红色 + "已逾期X天"，排在最上面
- 已完成 = 灰色划线，折叠到"已完成"分组

操作：
- 点击勾选完成/取消
- 长按：编辑
- **右滑出现快捷按钮**：开始 / 完成 / 删除
  - 点"开始"：弹出计时规则选择弹窗，可选该科目预设规则，也可临时选正计时/倒计时多少分钟，确认后立即开始计时
  - 点"完成"：直接标记完成
  - 点"删除"：删除该待办

### 今日任务区
今天该做的所有任务混在一起，包括两类：

**1. 重复型任务**（习惯养成类，如背单词）：
- 按重复规则自动出现（每天/每周几/每月几号）
- 黑色文字，打勾后灰色划线，下一个重复日重新出现
- 当天没打勾第二天自动消失，不逾期不顺延

**2. 单次任务**：
- 来源一：从科目目录里选的网课小节（自动绑定科目和章节），排了今天的计划日期
- 来源二：手动添加的一次性任务（如"做操作系统习题"），可绑定科目也可不绑，有计划日期，没完成会顺延
- 顺延欠债任务 = 红色文字，排在前面
- 当天新排 = 黑色文字
- 已完成 = 灰色划线
- 没绑定科目的手动任务，在统计页归为"其他"

排序：红色欠债任务 > 其他任务。

每条显示：任务标题、所属科目（如有）、计划日期。

**添加今日任务**：
- 点页面上的"添加任务"按钮，弹出选项：
  - 从科目目录选择：浏览科目→章节→小节，选好后设置计划日期
  - 手动输入：输入标题，可选绑定科目，设置计划日期

操作：
- 点击勾选完成
- 长按菜单：
  - 单次任务：改计划日期 / 编辑标题 / 加备注 / 延后到明天
  - 重复任务：编辑重复规则
- **右滑出现快捷按钮**：开始 / 完成 / 删除
  - 点"开始"：弹出计时规则选择弹窗，可选该科目预设规则，也可临时选正计时/倒计时多少分钟，确认后立即开始计时，自动绑定当前任务
  - 点"完成"：直接标记完成
  - 点"删除"：删除该任务

**批量清债**：当红色欠债任务超过3个时，顶部出现一个按钮"跳过过去N天的逾期任务"，点击后把过去所有未完成小节标记为跳过（不删除，不算完成，不再显示在首页）。

操作：
- 点击勾选完成
- 长按菜单：改计划日期 / 编辑标题 / 加备注 / 删除 / 延后到明天

### 计时进行中
- 通知栏常驻控制：暂停/继续/结束按钮
- App内顶部概览条下方显示一条计时状态条：当前科目/任务 + 已计时时长，点击可展开暂停/结束
- 结束自动保存一条学习记录，自动绑定当时开始的那条任务
- 倒计时结束 / 正计时到3小时：静默停止，自动保存
- **计时结束 ≠ 任务完成**：任务完成必须手动打勾，计时只记录时长

## Tab2 科目目录页

### 科目目录列表（默认全部折叠）
每个科目是一张可展开的卡片，折叠状态下显示：
- 科目名称
- 该科目累计学习时长
- **下方进度条**（只有设置了目录的科目才显示）：已完成小节 / 总小节
- 卡片右侧：**"开始"按钮** → 点击弹出计时规则弹窗，确认后开始计时，绑定该科目
- 卡片最右侧：**小三角箭头** → 点击展开/折叠目录

展开后：
- 章节列表，每章小标题
- 小节条目：标题、计划日期、完成状态（红/黑/灰划线）
- 每个小节右侧：**"开始"按钮** → 点击开始计时，绑定该小节
- 左滑小节条目：出现"完成" / "删除"按钮

其他操作：
- 长按科目卡片：编辑科目（改名称/备注/计时规则/删除科目）
- 长按小节：改计划日期 / 编辑标题 / 加备注 / 延后到明天
- 右上角：新增科目、导入目录
- 章节展开后右上角：新增章节、新增小节、导出本科目目录
- 注意：手动添加的单次任务（不绑定章节的）不在此页显示，只出现在首页今日任务里

### 导入目录（两种方式）
1. **粘贴文字自动解析**：
   - 从网课平台复制大段目录文字粘贴进来
   - 自动识别数字编号（第X章 / X. / X.X / X.X.X）分层
   - 弹出预览界面，确认无误后导入
   - 预览里可手动调整层级
2. **手动添加**：一节一节录入

### 重复任务管理
- 在科目页或设置页管理所有重复任务
- 新增重复任务：标题、选重复规则、绑定科目

## Tab3 统计页

### 顶部数字卡片
- 连续学习天数
- 累计总学习时长
- 本月总学习时长

### 图表区
- 柱状图：每日学习时长（按科目分色堆叠）
- 饼图：筛选区间内各科目时长占比
- 网课完成总览：所有科目合计完成进度

时间筛选：日 / 周 / 月

### 学习记录流水
- 倒序列表
- 每条显示：科目、时长、时间
- 操作：编辑时长、删除记录、补记一条（选科目、选日期、填时长）

### 每周学习周报
每周自动生成一次，内容包含：
- 本周总学习时长 / 日均时长
- 完成了多少节网课
- 连续学习天数
- 各科目时长分布
- 下周已排的任务预览

## Tab4 设置页

- **数据管理**：导出全部数据JSON / 导入备份（覆盖模式）
- **清空数据（分档）**：
  - 清空所有学习记录（保留目录、计划、待办、重复任务）
  - 清空所有科目目录（保留学习记录）
  - 全部清空
  - 每档都二次确认弹窗
- **外观**：
  - 深色/浅色模式切换
  - 主题颜色选择
  - 字体大小调节
- **提醒**：
  - 每日学习提醒开关（晚上9点通知：今日未完成任务数 + 逾期待办数）
- **关于**：版本号

---

## 数据库表结构（6张表）

1. **Subject 科目**：id, name, remark, createAt, timerMode(positive/countdown), timerDuration(倒计时分钟数)
2. **Chapter 章节**：id, subjectId, title, sortOrder
3. **Section 单次任务（网课小节/手动任务）**：id, chapterId(可空), subjectId(可空), title, note, isFinished, isSkipped, planDate, finishDate, source(course/manual)
4. **Todo 待办事项**：id, title, ddl, isFinished, subjectId(可空), note, createdAt
5. **RepeatTask 重复任务**：id, title, subjectId(可空), repeatType(daily/weekly/monthly), repeatValue(周几用逗号分隔/每月几号), note, createdAt
6. **StudyRecord 学习记录**：id, subjectId(可空), subjectName(冗余存科目名，科目删了也不丢), sectionId(可空), todoId(可空), repeatTaskId(可空), startTime, endTime, durationSec
