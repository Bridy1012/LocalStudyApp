# 第六版bug修复

## Bug 修复：左滑操作栏显示异常

**现象（首页待办 / 已完成待办 / 今日任务均复现）**

1. 操作按钮（开始 / 完成 / 删除、开始 / 恢复 / 删除）**默认常驻显示**，没有收在卡片右边界外，直接占掉约半屏宽度。
2. 按钮区**直接叠在任务内容上**：按钮文字压在任务标题上（例如「开始」压在「财政与税收选题与数据计划」「财政与税收数据与方法核查」上）。
3. 因为按钮常驻，标题可用宽度被压缩，长标题被挤压、遮挡、换行。
4. 已完成待办同时出现「开始」和「恢复」，语义冲突。
5. 卡片背景与按钮区之间没有正确层级/裁剪，视觉上像两套内容叠在一起，用户无法分辨"未滑动"与"已滑开"两种状态。

**期望实现**

1. **默认收起**：操作按钮完全位于卡片右边界之外，并被容器裁剪；不可见、不可点击、不进入无障碍焦点，默认状态下看不到任何按钮文字。
2. **左滑展开**：内容层整体左移，按钮从右边缘滑出；滑出距离 = 按钮区总宽度；松手按位移阈值 + 速度吸附为「展开」或「收起」，滑动中内容层不允许出现透明遮罩叠字。
3. **不遮挡内容**：内容层与按钮层分离，内容层宽度不变、只做水平位移，任何文字都不被按钮覆盖；按钮区改为紧凑排布（图标 + 文字，单按钮约 64–72dp），不要占半屏。
4. **单行展开**：同一时间只允许一行处于展开态；点击其他行或上下滚动时，上一行自动收起。
5. **展开态点击内容区不触发任务跳转**，只有点击按钮才执行对应动作。
6. **已完成任务按钮组规则**：不出现「开始」，只保留「恢复 / 删除」。
7. 科目目录页小节复用同一组件，行为一致。
